Diseña una app desktop llamada lolterm. No es un IDE ni un chat de agentes. Es un multiplexor gráfico tipo tmux/Zellij con chrome de editor (como VS Code / Cursor): orquesta CLIs reales (bash, nvim, lazygit, claude, ssh) dentro de terminales. Referencia: TUI mint de sammwy convertida a ventana nativa (light Sage).

Canvas: 1440×900, desktop Linux, una sola pantalla (home + workspace). Estilo: IDE claro mint, limpio, denso, 8px grid, radios 6–8px, sin sombras pesadas, sin glassmorphism, sin ilustraciones, sin mascotas.

Tokens:
- fill #ECF2EC
- bar #D6E4D6
- text #28302A
- muted #6C8070
- brand #488C58
- focus/tab activa #A8D4B0
- err #B04040
- pane bg #F4F7F4
- border #C5D4C5
Tipografía UI: Inter / system sans 12–13px. Terminal: JetBrains Mono 13px, texto #28302A sobre #F4F7F4.

Chrome (de arriba abajo, de izquierda a derecha):
1) Titlebar custom 32px (NO menú File/Edit/View del OS). Izquierda: wordmark “lol” brand + “term” focus. Centro: pills de workspace (proyecto:rama). Derecha: — □ × (minimizar, sidebar, cerrar).
2) Activity rail 40px: iconos texto ⌂ F ± > ☁. El activo es radio ⊙ sobre fondo focus, el resto ○ muted. Click otra vez oculta sidebar.
3) Sidebar 240px fondo bar: según rail.
   - ⌂ Inicio: recientes + “abrir carpeta…”
   - F Explorer: fila “Files | Search | Replace” (Files activo). Árbol con ▸ ▾ · y marcas git M A ? en err/ok.
   - ± Git: branch, chips +n -n, botón lazygit, lista corta de git log --oneline.
   - > CLIs: checklist [x]/[ ] nvim lazygit btop yazi claude opencode…
   - ☁ Remoto: /ts-ssh /ssh, hosts recientes.
4) Área editor:
   - Tab strip 32px: pills “> bash” “✦ claude” “± lazygit”, activa invertida (texto oscuro sobre mint), × a la derecha de cada pill, + al final.
   - Breadcrumb 24px muted: proyecto › src › archivo.
   - Cuerpo: 1 o 2 panes de TERMINAL (prompt realista). Split vertical 50/50 con divisor 4px bar. El pane con foco tiene borde 2px focus.
5) Status 28px bar: git:master* · path · ts:host · “Ctrl-b paleta”.

Overlays (opcionales, no tapar el prompt):
- Paleta comando centrada abajo, borde double brand, prompt “> ”.
- Git history: card 280×160 bottom-left, borde double, 6 líneas oneline. No un cliente git completo.

Estados a entregar (frames separados):
A) Workspace: explorer + tab bash + tab claude (activa) + git overlay.
B) Inicio: lista de proyectos recientes.
C) Paleta /run abierta.
D) Split bash | nvim.

No incluir: marketplace, Copilot, chat agent, minimap, breadcrumbs de VS Code con archivos abiertos en Monaco. El “editor” es siempre una terminal. Look: ligero, mint, profesional, latino, denso como un ADE TUI pasado a GUI.
